Guía de Integración Rápida en Moodle

Sigue estos sencillos métodos para mostrar este dashboard a tus coordinadores, tutores o directores de curso en Moodle.

1 Método Recomendado: Bloque HTML o Página Moodle

Ideal para añadir como bloque lateral en el Área Personal (Dashboard), en un curso de coordinación o como Recurso tipo "Página".

  1. En Moodle, pulsa en "Activar modo de edición".
  2. Haz clic en "Añadir un bloque" → Selecciona "HTML".
  3. Configura el bloque y en el editor haz clic en el icono < / > (Código HTML).
  4. Pega el código de incrustación que se muestra a continuación y guarda los cambios.
Código iFrame Moodle
2 Método Directo: Subir como Archivo HTML al Curso

Puedes subir este archivo autónomo a los archivos del curso de Moodle sin extensiones de servidor.

  1. En el curso de Moodle, haz clic en "Añadir una actividad o recurso".
  2. Selecciona "Archivo" o "Área de texto y medios".
  3. Sube este archivo HTML y configúralo como "Incrustar".
  4. Configura restricciones para que solo roles directivos o tutores puedan verlo.
